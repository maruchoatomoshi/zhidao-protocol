================================================================
        ZHIDAO Protocol —— 天昊管理员完全指南
================================================================

本文档面向中方带队老师 天昊（Тяньхао）。
目标：让你完全理解这款应用的所有功能 —— 积分、评分、排行榜、
商店、抽卡、活动、管理后台等。

应用界面是「俄语 + 中文」混合的（赛博朋克 / NetWatch 风格）。
本指南里，每个功能后面都会标注界面上的俄语按钮原文，
方便你在手机上找到对应位置。

最后更新：2026-06-15


----------------------------------------------------------------
0. 这是什么 / 整体概念
----------------------------------------------------------------

ZHIDAO Protocol 是一个「Telegram 小程序（Mini App）+ 后端服务器」
组成的游戏化系统，用于这次旅行（夏令营 / 研学）的日常管理。

它把日常管理任务（点名、日记、纪律）包装成一个带积分经济的游戏：

  - 学生写日记，老师评分 → 学生获得积分和声望。
  - 早晚点名确认出勤 → 获得抽卡机会。
  - 积分可以在商店消费、抽卡、做任务、参加突袭战。
  - 有特殊剧情活动（架构师协议 Architect / WildAI 入侵）。

通过 Telegram 机器人（bot）打开，会作为聊天里的按钮 / 菜单出现。

【两种核心数值，务必分清】

  积分 / 钱包：符号 ★
    - 内部货币，可花费、转账、被手续费消耗。
    - 可以消费。

  声望：符号 REP
    - 公开贡献度，反映学生表现。
    - 不能花、不能转、不能买。

一句话规则：REP 显示贡献，★ 显示钱包实力。

  - 公开排行榜用的是 REP，不是钱包余额。
  - REP 只能通过日记评分自动增长（以及缺勤扣分自动减少）。
  - 商店、礼物、任务、突袭、抽卡、卡片被动收入等都不影响 REP，
    只影响 ★。


----------------------------------------------------------------
1. 主屏幕和个人资料（Профиль）
----------------------------------------------------------------

  - 学生第一次进入时自动创建个人档案：名字、头像、路径（主题）、等级。
  - 主屏幕显示余额 ★ 和声望 REP。
  - 个人资料卡片包含：头像、路径、等级、称号、展示物品、统计、状态行。
  - 权限用中文标签显示：
      架构师（管理员特权）：架构师
      普通学生：学生节点


----------------------------------------------------------------
2. 日记和评分系统（这是你最常用的功能）  ★重要★
----------------------------------------------------------------

日记是整个系统的核心，REP 主要来源于此。

【学生怎么写】
  学生在小程序里写日记 / 提交日记，进入待审核状态。

【老师怎么评分】
  导航里的「ДНЕВНИК ★」（日记评分）就是评分入口。
  老师给日记打星 ★（1–3 星），可加奖励 bonus。
  评分自动转换为积分和声望：

      1 星           →  +15 ★   +15 REP
      2 星           →  +30 ★   +30 REP
      3 星           →  +50 ★   +50 REP
      额外奖励 bonus →  +20 ★   +20 REP

  「ДНЕВНИК ★」这个标签页显示日记排行榜——所有学生都会出现在这里，
  即使还没有任何评分（显示为 0）。

  旧的「扩展日记档案」只对管理员可见，导航里叫「АРХИВ」（档案）。
  普通学生看不到也打不开。

重点：星 ★ 是日记评分，积分 ★ 是货币。
      打分后系统自动把评分转换成积分 + 声望。


----------------------------------------------------------------
3. 点名 / 出勤（Перекличка）
----------------------------------------------------------------

  - 每天早上和晚上各有一次点名，学生需要确认「我在场」
    （通过按钮 / 扫描）。
  - 每次成功确认 → 获得 1 次抽卡机会（scan attempt），
    每周最多 7 次。
  - 错过点名 → 扣分（扣 ★ 和 REP），除非被防护类道具挡住。
      默认缺勤罚款：-50 ★（可被卡片 / 植入物被动减免或抵挡）。

  管理员可以在后台「Перекличка」区看到所有人的出勤状态。


----------------------------------------------------------------
4. 排行榜 / 评分（Рейтинг）
----------------------------------------------------------------

导航里的「Рейтинг」（排名）：

  - 上方：按 REP 排序的总排行榜（operator 卡片）。
  - 下方：单独的日记排行榜。
  - 阿尔法老大（МЮ / 米哈伊尔·尤里耶维奇）显示为顶部高亮区块，
    不算作第 1 名。


----------------------------------------------------------------
5. 商店（Магазин / 商店）
----------------------------------------------------------------

导航「Магазин」：

  - 商店标签：用 ★ 购买道具 / 奖品。
  - 库存（инвентарь）标签：查看已购买的物品，
    可以使用 / 赠送 / 出售。

经济规则：

  购买            →  物品价格（Guanxi/Zhongli 卡可打折）
  赠送税          →  20 ★（有 Fox 卡每天一次 15 ★）
  普通学生赠送上限 →  5 次 / 天
  出售返还        →  50%（有 Panda 植入物 60%）

后台有监控，会跟踪重复的赠送对子和「任务 + 赠送」重叠，防止刷分。


----------------------------------------------------------------
6. 抽卡 / 卡池（Казино / 箱子 + 祈愿）
----------------------------------------------------------------

导航「Казино」。抽卡消耗抽卡机会（scan attempt），不直接花 ★。

【抽卡机会从哪来，上限 7 次】
  - 早 / 晚点名确认：+1
  - 当天第一篇日记达到 3 星：+1
  - 商店道具 extra_case：+1
  - Zhongli 卡当天第一次购物：+1
  - Moon 卡晚上确认 / 天：+1

【两种抽卡形式】

  1）箱子（Кейсы / 箱子）—— 赛博朋克路径
     - 金 / 紫 / 黑 三档。
     - 可能现金奖励：+30 ★ / +60 ★ / +100 ★。
     - 可能掉落：道具 / 植入物（implant）。

  2）祈愿（Молитвы / 祈愿）—— 原神主题路径
     （界面变成原神抽卡风格）
     - 蓝 / 紫 / 金 池。
     - 可能现金奖励：+30 ★ / +60 ★。
     - 可能掉落：卡片（card）/ 免疫 / 自由时间道具。

  注意：抽卡的概率由后端决定，是权威的。
       前端只负责展示结果，不要随意改概率。

【植入物 / 卡片，被动加成】
  - 植入物 implant 属于赛博朋克路径；卡片 card 属于原神路径。
  - 切换到另一条路径时，对应被动会被「冻结」
    （不会丢失，只是暂时不生效）。
  - 重复掉落可以「拆解」回收：卡片 +50 ★，植入物 +50 ★。

  （完整的被动效果列表见文末「经济参考表」。）


----------------------------------------------------------------
7. 突袭战（Рейд / Raid）
----------------------------------------------------------------

导航相关入口「Рейд」：

  - 入场费：-50 ★
  - 胜利奖励：+100 ★
  - 胜率：40%
  - 期望值：0.4 × 100 − 50 = -10 ★
    （所以突袭是轻微的「消耗」，不是刷钱手段）
  - 每人每天最多 2 次个人尝试，公开突袭每天 3 次。

  部分卡片有突袭返还被动（Pyro / Star）。


----------------------------------------------------------------
8. 任务板 / 委托（Доска поручений / 任务板）
----------------------------------------------------------------

入口按钮「📋 ДОСКА」（在商店页切换过去）：

  - 学生之间、师生之间发布和接取任务，完成获得 ★。
  - 学生赏金范围：5–50 ★；管理员：5–100 ★。
  - 每个发布者同时活跃任务：3 个。
  - 每个工人每天完成：5 个。
  - 发布者每日花费上限 150 ★，工人每日赚取上限 150 ★。
  - 手续费：10%，最低 2 ★（完成后销毁）。
  - 5 分钟内完成会被标记为「可疑」，禁止自接自己的任务。
  - 允许匿名发布，但后台监控保留真实身份。

管理员在后台「Контракты」区可以监控所有任务（含真实身份）。


----------------------------------------------------------------
9. 礼品码（Подарочный код / МЮ）  ★新功能★
----------------------------------------------------------------

导航「ЕЩЁ」（更多）→「КОД МЮ」（МЮ 的礼品码）：

  - 学生输入由米哈伊尔·尤里耶维奇（МЮ）发放的礼品码 → 自动到账 ★。
  - 输入成功后会弹出 МЮ 角色弹窗（红色风格）确认奖励。
  - 同一个码每人只能使用一次；支持使用次数上限和过期时间。

【管理员如何创建礼品码】
  后台「Коды」标签页：
    1. 填写：码（例 ZHIDAO2026）、奖励 ★、使用次数上限、备注（可选）。
    2. 点「🎟 СОЗДАТЬ КОД」（创建码）。
    3. 下方列表显示所有已创建的码及使用次数。

10. 剧情活动：架构师协议（Architect Protocol）
----------------------------------------------------------------

这是一个中心化的剧情 / Boss 战系统（「Architect」）：

  - 全屏战斗视频 / 背景，悬浮 HUD、战斗日志、指令面板。
  - 学生通过 4 种行动参战，每个行动会弹出一道问题，答对有加成：
      攻击 Attack   ：直接伤害，第 1 阶段最有用。
      协议 Protocol ：高战术伤害，后期更强。
      同步 Sync     ：开启 / 辅助弱点窗口，控制 / 支援。
      稳定 Stabilize：支援行动，管理压力 / 过载。
  - 有「架构师日志（ДНЕВНИК АРХИТЕКТОРА）」剧情记录系统，
    藏在「ЕЩЁ → АЧИВКИ」（成就）里。学生达成首次抽卡、
    首次获得物品等里程碑时，会弹出架构师角色弹窗讲一段剧情。

管理员可在后台用「Architect」按钮触发全局活动警报。

11. 主题（Темы / 主题）
----------------------------------------------------------------

「ЕЩЁ → ТЕМЫ」：可切换界面外观

  - NetWatch（赛博朋克，深色 / 默认）
  - NetWatch 浅色
  - 原神 浅色 / 深色

切换主题会同时切换「路径」（赛博朋克 ↔ 原神），
影响植入物 / 卡片哪一类被动生效。

13. 管理后台（АДМИН）  ★这是你管理全员的地方★
----------------------------------------------------------------

入口：「ЕЩЁ（更多）→ АДМИН（管理员）」
     （只有管理员账号能看到这个按钮）。
顶部标题「NETWATCH PROTOCOL // Панель управления（控制面板）」，
右上角「👑 ADMIN」。

后台用一排图标按钮切换不同区块：

  Расписание   （课程表 / 日程）
      添加 / 删除每日课程（日、时间、科目、地点）
  Объявления   （公告）
      发布全员公告
  Игроки       （玩家）
      搜索学生、查看档案、冻结账号、调整积分、查看操作日志
  Перекличка   （点名）
      查看所有人出勤状态
  Стирка       （洗衣）
      管理洗衣机 / 饮水排班（含「水」子标签）
  BlackWall    （黑墙）
      BlackWall 视觉 / 状态、架构师活动可用性
  Контракты    （任务）
      监控所有任务（含真实身份）
  Отчёт        （报表）
      经济日志：按 7 天 / 30 天 / 全部 查看每个玩家的收支
  Коды         （礼品码）
      创建 / 查看礼品码（见第 9 节）
  Architect    （架构师）
      触发全局架构师活动警报

【管理后台最常用的操作】

  A) 调整某个学生的积分
     1. 进「Игроки」（玩家）。
     2. 搜索学生（名字或 ID）。
     3. 调整 ★ 余额（用于奖励 / 纠错）。
        这会写入经济日志，可在「Отчёт」查到。
     4. 调整 REP 要用专门的 REP 操作（独立于钱包）。

  B) 冻结 / 解冻账号
     在「Игроки」里把某个学生标记为「冻结」。
     冻结后该学生无法抽卡 / 购物（受 NetWatch 监管状态）。

  C) 给日记评分
     用导航的「ДНЕВНИК ★」（不是在 АДМИН 里），打星 + bonus。

  D) 发公告
     「Объявления」→ 输入文字 →「📣 ОПУБЛИКОВАТЬ」（发布）。

  E) 创建礼品码
     「Коды」→ 填码 + 奖励 ★ + 次数 →「🎟 СОЗДАТЬ КОД」。

14. Telegram 机器人命令（管理员快捷操作）
----------------------------------------------------------------

机器人主要用于快速的管理动作
（日记编辑仍在小程序里完成）：

  /diary_status YYYY-MM-DD
      查看某天日记概况：谁填了、谁交了、谁还缺、哪些已评分。

  /diary_score TELEGRAM_ID YYYY-MM-DD LESSON_SCORE DIARY_SCORE
      不打开网页快速打两个分。

  /diary_lock TELEGRAM_ID YYYY-MM-DD
      审核后锁定某天，防止后续修改。

  （机器人是第二个写入进程，发放工资、被动收入等也走机器人；
   技术细节见 CLAUDE.md。）

16. 天昊的日常建议流程
----------------------------------------------------------------

每天大致这样用就够了：

  1. 早上 / 晚上点名后：
     进「АДМИН → Перекличка」看谁缺勤，必要时处理罚款。

  2. 日记：
     进「ДНЕВНИК ★」给当天日记打星（1–3）+ 视情况加 bonus。
     这一步自动给学生发 ★ 和 REP。

  3. 需要奖励 / 纠错积分：
     「АДМИН → Игроки」搜人 → 调整 ★。

  4. 要发通知：
     「АДМИН → Объявления」发公告。

  5. 要发奖励码：
     「АДМИН → Коды」创建礼品码，把码发给学生。

  6. 想看谁刷分 / 经济异常：
     「АДМИН → Отчёт」看经济日志，「Контракты」看任务监控。

  7. 排行榜随时看「Рейтинг」。


----------------------------------------------------------------
17. 注意事项
----------------------------------------------------------------

  - REP ≠ ★：日记影响两者，其它玩法只影响 ★。
    给日记打分是 REP 的唯一正常增长来源。
  - 抽卡概率、商店价格、经济数值由后端权威决定，
    请不要随意改动（改动前请联系开发者 Марк）。
  - 礼品码、积分调整都会写入经济日志，可追溯。
  - 80 ★ 是一个有意设置的门槛
    （学生需要先攒到一定积分才能在抽卡上消费）。
