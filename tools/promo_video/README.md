# Промо-ролик ZHIDAO Protocol (25 с, 9:16, 1080×1920)

Ролик собирается из **реальных экранов приложения**: ничего не нарисовано и не выдумано.
Композиция -- детерминированная HTML-страница, кадры снимает Edge, кодирует ffmpeg.

| Файл | Что делает |
|---|---|
| `capture.mjs` | съёмка 1: тела экранов (Сегодня, Ивенты, карта, кейсы, REP) по частям, для прокрутки внутри телефона |
| `capture2.mjs` | съёмка 2: целые экраны телефона (разделы и окна игр), размеры полос приложения и ячейки коллекции в `captures/meta.json` |
| `index.html`, `timeline.js` | композиция: телефоны с наклоном и прокруткой, рабочий стол XP, курсор, Flip 3D, кинетический текст, аэро-декор; `seek(t)` ставит стили по времени, ничего не анимируется само |
| `render.mjs` | `node render.mjs` -- полный рендер в `out/ZHIDAO-promo-25s.mp4`; `node render.mjs --keys 3,8.8,22` -- только контрольные кадры в `out/keys/` |
| `contact.py` | контактный лист контрольных кадров `out/contact.png` |

```powershell
cd tools\promo_video
npm install
# 1) поднять стенды (см. ниже), снять экраны
node capture.mjs
node capture2.mjs
# 2) отрендерить
node render.mjs
```

## Стенды для съёмки

- Стенд A (8795): оператор и 6 участников, открыт рынок, лобби Зомби и Саботажа. `case.student2` получает
  в тестовой базе девять имплантов и три попытки (иначе экран «Коллекция» пуст, а кнопка скана неактивна).
- Стенд B (8796): один безымянный участник «Участник» -- для экрана REP без чужих имён и чисел.
- Стенд C (8797): свежий раунд Протокола 60 с тремя живыми игроками (на стенде A раунд к моменту съёмки
  уже закончился), `case.student1` открывает вопрос. Таймеры раунда растянуты (`run_all.py`).
- Часовой пояс сезона `America/New_York`, чтобы рынок (09:00-21:00 по сезону) был открыт.
- Тема светлая, оформление «Луна-Аква» (`?design=xp`). Инлайновые `<style>` режет CSP, поэтому скрытие
  служебной строки делается через CSSOM (`style.setProperty`).

## Правила

- Логотип -- `zhidao_v4/static/app/assets/zhidao-dragon-logo.png`, без изменений пропорций и надписей.
- Коллекция -- иллюстрации из каталога имплантов, без счётчиков владельцев и без слов про выигрыш/дроп.
- `captures/` и `out/` в git не попадают; готовый MP4 отдаётся отдельно.
- Экрана «Задания» в V4 нет, поэтому вместо него показан REP.
- Декор (рабочий стол, курсор, окна, сферы, пузыри, Flip 3D) нарисован в CSS как отсылка к стилю XP / Frutiger Aero; логотипов и ресурсов Microsoft нет.
