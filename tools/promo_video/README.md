# Промо-ролик ZHIDAO Protocol (25 с, 9:16, 1080×1920)

Ролик собирается из **реальных экранов приложения**: ничего не нарисовано и не выдумано.
Композиция -- детерминированная HTML-страница, кадры снимает Edge, кодирует ffmpeg.

| Файл | Что делает |
|---|---|
| `capture.mjs` | снимает экраны с двух локальных стендов в `captures/` (Сегодня, Ивенты, карта, кейсы, Протокол 60, REP) |
| `index.html`, `timeline.js` | сцены и таймлайн: `seek(t)` ставит стили по времени, ничего не анимируется само |
| `render.mjs` | `node render.mjs` -- полный рендер в `out/ZHIDAO-promo-25s.mp4`; `node render.mjs --keys 3,8.8,22` -- только контрольные кадры в `out/keys/` |
| `contact.py` | контактный лист контрольных кадров `out/contact.png` |

```powershell
cd tools\promo_video
npm install
# 1) поднять стенды (см. ниже) и снять экраны
node capture.mjs
# 2) отрендерить
node render.mjs
```

## Правила

- Логотип -- `zhidao_v4/static/app/assets/zhidao-dragon-logo.png`, без изменений пропорций и надписей.
- Коллекция -- иллюстрации из каталога имплантов, без счётчиков владельцев и без слов про выигрыш/дроп.
- `captures/` и `out/` в git не попадают; готовый MP4 отдаётся отдельно.
- Экрана «Задания» в V4 нет, поэтому в сцене 13-18 с вместо него показан REP.
