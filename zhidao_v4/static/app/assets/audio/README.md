# Музыка участнического приложения

Сюда кладутся звуковые файлы, `playlist.json` описывает порядок.

## Как добавить песни

1. Скопировать файлы в эту папку.
2. Пересобрать манифест:

   ```powershell
   .\.venv-web\Scripts\python.exe tools\build_playlist.py
   ```

   Скрипт читает теги ID3, если они есть, и иначе разбирает имя файла вида
   `Исполнитель - Название.mp3`. Уже проставленные вручную названия он не
   затирает — только дописывает новые файлы и убирает исчезнувшие.

Манифест приложение запрашивает с `cache: no-cache`, поэтому версию поднимать
не нужно — новый список подхватится сам, достаточно обновить страницу.

Вместо командной строки можно просто дважды щёлкнуть **«Обновить плейлист.bat»**
в этой же папке — он делает ровно то же самое.

## Формат

- **MP3 или AAC/m4a.** Только OGG/Opus не годится: Safari их не играет, а
  половина участников придёт с iPhone.
- **96–128 kbps.** Приложение работает на мобильном интернете в Китае;
  каждый лишний мегабайт — это секунды ожидания и чужой трафик.
- Файлы тянутся по одному, по мере воспроизведения (`preload="none"`),
  весь список заранее не скачивается.

## Права

Если это чужие коммерческие записи, раздача их шестидесяти участникам через
приложение — это распространение, а не личное прослушивание. Для внутреннего
инструмента поездки это решение владельца проекта, но принимать его надо
осознанно, а не по умолчанию.
