Счётчик ★ — используй только в шапке приложения; на экранах баланс не повторяется.

```jsx
<HitCounter value={212} digits={4} />
```

Пока сервер не ответил, передавай `value={null}`: ячейки останутся пустыми, вместо выдуманного числа. Для таймера раунда и показаний прибора возьми `<LcdPanel>` — у него другой фон, и смешивать их нельзя.
