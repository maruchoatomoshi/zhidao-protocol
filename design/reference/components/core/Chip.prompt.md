Чип — используй для короткой отметки у элемента: награда, дубль, пример, «идёт сейчас».

```jsx
<Chip tone="reward">+2 ★</Chip>
<Chip tone="dupe">дубль · обмен</Chip>
<Chip tone="example">пример в макете</Chip>
<Chip dot>идёт сейчас</Chip>
```

Чип не кнопка: если по нему надо нажимать, это `<Button variant="system">`.
