Карточка — используй для любого блока контента внутри экрана.

```jsx
<Card label="СЕЙЧАС" title="Мой день" titleCn="我的一天">
  <p className="zd-sub">Расписание вводит вожатый в консоли.</p>
</Card>
```

У каждого крупного блока китайское название через `titleCn`. Не вкладывай карточку в карточку — вложенный блок делай строкой или таблицей.
