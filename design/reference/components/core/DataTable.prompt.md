Таблица — используй в Луне-Акве там, где в Акве строки карточек: витрина магазина, списки консоли вожатого.

```jsx
<DataTable selectedId={sel} onSelect={setSel}
  columns={[{key:"name",label:"Название"},{key:"price",label:"★",width:56}]}
  rows={[{id:"wall-1",name:"Обои «Прилив»",price:"120"}]} />
```

Имён участников в таблицах не бывает: ни кто оценил, ни с кем был обмен.
