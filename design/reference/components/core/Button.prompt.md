Кнопка ZHIDAO — используй для любого действия участника или вожатого; материал выбирается вариантом, а не цветом.

```jsx
<Button variant="primary">Сканировать</Button>
<Button variant="system">Коды привязки</Button>
<Button variant="confirm" confirmLabel="Точно? −300★" onClick={buy}>Купить купон</Button>
```

- `primary` — синий пластик, одно главное действие на экран.
- `secondary` — стекло/бумага, всё остальное.
- `system` — хром и моноширинная подпись в Акве, обычная кнопка Tahoma в Луне: орган управления протоколом, не действие участника.
- `action` — лайм, только для «сделать сейчас» в окне игры.
- `confirm` — списание ★ и любое необратимое: первое касание взводит кнопку (янтарные `#d9822b` / `#fff3e2` / `#8a4a00`), второе выполняет.
- Красной кнопки нет. Красный в приложении носит только шильдик системного администратора.
- Неготовую функцию не рисуй кнопкой: ставь `disabled` и объясни в `<Note>`.
