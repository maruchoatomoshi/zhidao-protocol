ЖК-поверхность — используй для таймера раунда и показаний прибора в окне игры.

```jsx
<LcdPanel value="07:20" caption="ДО КОНЦА РАУНДА" />
<LcdPanel value="00:45" caption="ДО КОНЦА РАУНДА" low />
```

`ghost` должен совпадать с форматом значения (ММ:СС → `88:88`). Фон не смешивай со счётчиком в шапке: у счётчика ячейки, здесь поверхность.
