Пустое состояние — используй вместо выдуманных строк: сезон не начался, ничего не куплено, пустая коллекция, нет связи.

```jsx
<EmptyState title="Коллекция пуста" action={<Button variant="secondary">Открыть кейсы</Button>}>
  Импланты появляются из кейсов и обменов.
</EmptyState>
```

Скажи причину и, если действие есть, дай ровно одно.
