Артборд телефона — оболочка любого экрана; пары «Аква / Луна-Аква» ставь рядом.

```jsx
<PhoneFrame skin="luna" theme="dark" label="Магазин — Луна-Аква, ночь"
  header={<AppHeader stars={212} />} nav={<BottomNav value="more" />}>
  …экран…
</PhoneFrame>
```

390×844, работает на 320 px, зоны нажатия от 44 px. Строку состояния телефона и клавиатуру не рисуем.
