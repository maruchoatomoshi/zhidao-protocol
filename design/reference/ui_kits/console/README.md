# Консоль вожатого на телефоне

Источник: `zhidao_v4/static/app/admin.js`, `diary.js`, `zhidao_v4/cases_api.py`,
`zhidao_v4/diary_api.py`, `V4_AUTH.md` §1b. Отдельного планшетного вида нет:
тот же артборд 390×844 и те же два оформления, что у участника.

## Чего в макете нет и почему

- **Выдачи ★ отдельной кнопкой.** У сервера такой команды нет: ★ начисляются
  оценкой дневника, кейсами и играми. Рисовать кнопку значило бы изображать
  неготовую функцию рабочей. Ручной канал один и подписан на листе: бонус
  дневника.
- **Полного рейтинга и «кто с кем встречался».** В консоли этого не
  появляется: правило приватности действует и для служебного контура.
- **Перекличка и запись на стирку.** В приложении они подписаны как
  «подключится вместе с расписанием»; здесь их нет.

## Принятые решения (2026-09-16)

1. **Выдача ★**: решено — единственный ручной плюс — бонус дневника, он уже
   существует и уже даёт ★ · отклонено: серверная команда с лимитом (новая
   экономика и новый журнал), «не делать вовсе» (оставляет вожатого без
   альтернативы).
2. **Ввод расписания дня**: решено — строками «время — что» вручную ·
   отклонено: каталог готовых блоков (согласованного списка ещё нет), один
   текст на день (ломает зафиксированный список по времени в «Моём дне»).
3. **Кому видно «Сводку»**: решено — вкладка видна с пометкой «нужна роль
   архитектора» до нажатия · отклонено: клик-и-отказ без пометки (тупик),
   спрятать вкладку (роли становятся невидимыми; это не приватность между
   детьми, а административный раздел).

Открытых вопросов по консоли больше нет. Осталось внешнее условие: сохранение
расписания включится, когда появится серверная команда.
