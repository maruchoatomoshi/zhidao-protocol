# Окна игр по состояниям

Лобби → идёт раунд → итог для двух крайних случаев: «Протокол 60» (длинная
игра на всю смену) и «Шпион» (настольная на один вечер). Каждый экран —
артборд 390×844, пары «Аква / Луна-Аква» стоят рядом, ночь показана на самых
нагруженных состояниях.

## Откуда взято

- «Протокол 60» — это игра-шоу на вопросах, а не физическая битва:
  разметка и фиолетово-золотая сцена из `royale.css` (логотип, бегущая
  строка, вопрос с иероглифом, варианты, разбор, сетка живых, выбывание).
- «Шпион» — из `games.css`: плита кода комнаты, сегменты числа шпионов,
  список участников с точками готовности, карта роли, янтарная полоса
  предупреждения, вскрытие с наградой и список слов вечера.
- Таймер — ЖК-поверхность из `retro.css` (погасшие сегменты за цифрами,
  красный на исходе). Со счётчиком ★ в шапке он не смешивается.

## Данные

Сезон не начался: состав, код комнаты и число живых приходят с сервера,
всё остальное на макете — пример и подписано как пример. Имён нет ни в
списках, ни в сетке, ни в итоге; кто как голосовал, не показывается.

## Открытые вопросы

1. Ход длинной игры решён: «Живых: N из 60» одним числом с сервера плюс
   лента последних трёх выбываний (приём «последних трёх сигналов» из
   Кейсов). Бегущая строка и лента дней отклонены.
2. Ход ответов — полоса без цифр, видна всем участникам; точное число у
   вожатого в консоли.
3. Оживление — решением вожатого из консоли. Кнопка у участника отклонена:
   сервер оживление не умеет, а выключенную кнопку рисовать нельзя.
4. Награда в итоге «Шпиона» — «+★ угадавшим» без цифры: реальных чисел в
   экономике ещё нет. Подставим, когда появятся.

## Часть 2 — настольные и ролевые игры

`table-games.html` + `TableGames.jsx`: Контрабанда 走私 (smuggle.css),
Тайный агент 特工 (agent.css), Зомби-протокол 僵尸 (zombie.css), Саботаж
破坏 (sabotage.css) — по три состояния в двух оформлениях, ночь на раунде.

Правила безопасности стоят первой строкой там, где игра выводит людей на
улицу: «без бега и касаний» у Зомби, «станции по GPS, ходить шагом» у
Саботажа — обе строки взяты из кода (`.zombie-safety`, `.sabotage-safety`).

Решения по части 2 (2026-09-16):
1. «Рынок контрабанды» — вкладка «Прилавок / Рынок» внутри «Контрабанды»
   (market.css), как «Витрина / Моё» в Магазине.
2. Счёт «раскрыто» в «Тайном агенте» — только в консоли вожатого.
3. Личный код в «Зомби» — четыре цифры, поле числовое.
4. «Саботаж»: станция сдаётся кнопкой участника; автоматики по GPS нет,
   пока карта прототип.

## Часть 3 — поле и настольные

`field-games.html` + `FieldGames.jsx`: Захват кампуса 校园争夺
(capture.css), Шифровальщики 密码员 и Сбой системы 系统故障 (cipher-* и
outage-* из games.css).

Решения по части 3 (2026-09-16):
1. «Захват»: режим фракций накладывается на настоящий экран «Карта
   кампуса»; своей карты в окне игры нет.
2. «Шифровальщики»: подсказка говорится вслух. Приложение показывает
   только факт подсказки и число слов.
3. «Сбой системы»: руководство бумажное, у вожатого.

Все девять игр из брифа закрыты по трём состояниям.
