# Разделы «Ещё»

`index.html` + `Sections.jsx` + `Variants.jsx`.

## Готовые экраны
- **Обмен 交换** (trade.css): дубли, код напарника, конструктор «отдаёшь /
  получаешь», подтверждение вторым касанием. Имён в ленте нет.
- **Мастерская 工坊** (workshop.css): рецепты по ступеням, переплавка,
  результат. Цвет ступени — через `data-tier`, рецепт «четыре дубля» взят
  как есть.
- **Антивирус 杀毒** (virus.css): состояние заражения, окно ошибки, тест.
  Ничего не ломается и не прячется; дрожание гаснет вместе с анимациями.

## Спорные места — по три варианта, выбор за заказчиком
- **Встречи 见面**: кусок без источника / кусок с обезличенной пометкой
  места и времени / только счётчик собранного. Плюсы и минусы — в записке
  на каждом артборде.
- **Карта кампуса 校园地图**: туман плитками / мягкими пятнами вокруг
  посещённых точек / без картинки тумана, места списком. Схема на
  артбордах — подложка макета: настоящую географию даёт провайдер.

- **Архив скрытых файлов 档案** (story.css): послание словами, строки
  архива с замками «нужно прийти на место» и «сначала предыдущий», окно
  фрагмента в духе нулевых (поверхность через `data-surface`: место,
  корзина, свойства, битый ярлык, ICQ, окно ошибки), финал с эпилогом и
  подписью Архитектора. Награда за финал без числа: в экономике не назначена.
